# Sunro Systems — Official Website

Static website for **Sunro Systems**, a premium RO water purifier company.

Live at: [sunrosystems.com](https://sunrosystems.com)

## Stack
- Plain HTML5 + CSS3 + Vanilla JS
- No build tools required
- Hosted on GitHub Pages with custom domain

## Pages / Sections
- **Hero** — Tagline, CTA buttons
- **Stats** — Key business numbers
- **Products** — Home RO, Commercial RO, AMC Plans
- **Why Us** — 6 feature highlights
- **About** — Company story & highlights
- **Contact** — Enquiry form + contact details + WhatsApp

## GitHub Pages Setup
1. Go to repo → **Settings → Pages**
2. Source: `main` branch → `/ (root)`
3. Custom domain: `sunrosystems.com`
4. Add DNS A records at your registrar pointing to GitHub IPs:
   - `185.199.108.153`
   - `185.199.109.153`
   - `185.199.110.153`
   - `185.199.111.153`
5. Add CNAME record: `www` → `gopinath87607.github.io`

## Customise
- Update phone/address in `index.html` (search for `98765 43210` and `123, Water Street`)
- Replace social links in the footer
- Add your logo image to replace the 💧 emoji
